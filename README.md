# A Grade Amendment System - Frontend

Vue3 frontend for A Grade Amendment System.

## Production API

Production builds use same-origin API routing (`/api`) for merged frontend/backend deployment on a single Azure App Service. Keep `VITE_API_BASE_URL` empty in `.env.production`.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```


## Backend Connection

The frontend connects to the backend API at `http://localhost:3000`.

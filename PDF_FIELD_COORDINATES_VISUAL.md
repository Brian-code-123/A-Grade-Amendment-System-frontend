## PRACTICAL USAGE GUIDE

### Step 1: Determine Field Type
- **Text Field**: Use `drawText(text, x, y, size)`
- **Checkbox**: Use `drawText('✓', x, y, 28)` if selected
- **Image (Signature)**: Use `drawImage(pngUrl, x, y, 120, 48)`

### Step 2: Render in Correct Order
1. First, render all text fields (normal fields, 26pt)
2. Then tick marks for checkboxes (28pt)
3. Finally, signature images (120×48 PNG)

### Step 3: Handle Multi-line Details
```javascript
// For fields with multiple lines (like reason details)
// Y coordinates for each line:
line1_y = detailsY       // First line
line2_y = detailsY + 4.5 // Second line (approximate)
```

### Step 4: Coordinate Conversion (if needed)
- **Points to Pixels**: `pixels = points × (DPI / 72)`
- **Points to Inches**: `inches = points / 72`
- **Points to MM**: `mm = points × 25.4 / 72`

---

## DEBUGGING COORDINATES

If fields appear in wrong positions:

1. **Verify page size**: Ensure you're using 1581×2225 for page 1
2. **Check origin point**: X=0,Y=0 should be top-left corner
3. **Font size mismatch**: Compare rendered size with expected 26pt/22pt/28pt
4. **Baseline vs Top**: Verify if Y coordinate is baseline or top of text
5. **Image positioning**: Check if image X,Y is top-left or center
6. **Data formatting**: Ensure text durations match expected format
